# SCHD-0007: Student views their appointments list

**Summary:** Verify that a student can view a list of their appointments organized by status tabs, including count badges and empty states.

**Preconditions:**
- User is logged in with a **student** account
- The student has at least one appointment in the system

**Scenario 1: View appointments by tab**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the appointments page | Verify that the page loads with tab navigation (e.g., "Pending", "Upcoming", "Completed") |
| 2. The "Pending" tab is displayed | Verify that each pending appointment appears as a card showing the counselor's name/avatar, date, time, reason preview (truncated), and a "Pending" status badge |
| 3. Student clicks the "Upcoming" tab | Verify that approved (future) appointments are listed with status "Approved" and a blue/tertiary badge |
| 4. Student clicks the "Completed" tab | Verify that completed appointments are listed with status "Completed" |
| 5. The count badges on each tab | Verify that each tab shows the correct number of appointments matching that status |
| 6. Student clicks a tab where no appointments exist (e.g., "Completed" when none are completed) | Verify that an empty state message is displayed (e.g., "No completed appointments yet") |
