# AUTH-0007: Sign-up fails with an already-registered email

**Summary:** Verify that attempting to sign up with an email that is already registered shows a clear error and does not create a duplicate account.

**Preconditions:**
- A user account already exists with the email `existing@example.com`
- The user is on the sign-up page

**Scenario 1: Duplicate email sign-up attempt**

| Step | Expected Behavior |
|------|-------------------|
| 1. User enters the already-registered email, a new password, and confirms the password | Verify that the form accepts the input |
| 2. User clicks "Sign Up" | Verify that an error message appears: "An account with this email already exists" or similar |
| 3. User checks the page | Verify that the user remains on the sign-up page — no new account is created and no confirmation email is sent |
| 4. User clicks the "Log in instead" link (if available) | Verify that the user is taken to the login page where they can log in with the existing account |
| 5. User navigates back and tries with a different, unregistered email | Verify that the sign-up succeeds with the new email |

**Post-conditions:**
- No duplicate account is created
- The existing account is not affected
- The user can either log in with the existing account or sign up with a different email
