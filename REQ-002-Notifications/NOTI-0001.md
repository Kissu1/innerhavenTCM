# NOTI-0001: Student views the notification bell with unread count

**Summary:** Verify that the notification bell icon in the navbar displays a red badge showing the correct number of unread notifications.

**Preconditions:**
- User is logged in with a **student** account
- At least one unread notification exists for the student

**Scenario 1: Unread notification badge is displayed**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student is on any page with the navbar visible | Verify that a bell icon is shown in the top navigation bar |
| 2. Check for the unread badge | Verify that a small red badge appears on the top-right corner of the bell icon showing the number of unread notifications |
| 3. Verify the badge number | Verify that the number displayed matches the actual count of unread notifications |
| 4. Student opens the bell dropdown and marks all as read (see NOTI-0003) | Verify that the red badge disappears entirely after all notifications are marked as read |

**Post-conditions:**
- The badge correctly reflects the current unread count in real time
