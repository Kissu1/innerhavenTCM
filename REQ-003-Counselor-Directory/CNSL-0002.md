# CNSL-0002: Student views available time slots for a selected date

**Summary:** Verify that when a student selects a counselor and picks a date on the booking calendar, the available time slots appear — and any already-booked slot is excluded.

**Preconditions:**
- User is logged in with a **student** account
- A counselor exists with a weekly schedule (e.g., Mon–Fri, 9:00–17:00, 50-minute slots)
- The target date is a future weekday within the counselor's schedule
- One existing appointment is already booked at 10:00 on that date

**Scenario 1: Select date and view available slots**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the booking page and selects the counselor | Verify that the counselor is highlighted as selected and a calendar is displayed |
| 2. Student clicks on the target future date in the calendar | Verify that a grid of available time slots loads for that date (e.g., 9:00, 9:50, 10:40, 11:30, …) |
| 3. Student scans the time slot grid | Verify that the 10:00 slot is **missing** from the grid — it was already booked by another student |
| 4. Student checks the remaining slots | Verify that all other slots matching the counselor's schedule are still shown and selectable |

**Post-conditions:**
- Only unbooked time slots are displayed for the selected date
- The student can proceed to select any available slot to continue booking
