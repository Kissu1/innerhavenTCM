# NOTE-0005: Counselor views notes across multiple appointments

**Summary:** Verify that a counselor can see session notes for different appointments and students, with each note clearly associated with its respective appointment.

**Preconditions:**
- User is logged in with a **counselor** account
- The counselor has written session notes for appointments with at least two different students

**Scenario 1: Browse notes across appointments**

| Step | Expected Behavior |
|------|-------------------|
| 1. Counselor navigates to their appointments list | Verify that past appointments with session notes are distinguishable from those without (e.g., a notes indicator or icon) |
| 2. Counselor opens the first appointment with notes | Verify that the correct notes, recommendations, and follow-up plan for that specific appointment are displayed |
| 3. Counselor returns to the list and opens the second appointment with notes | Verify that a different set of notes is displayed — the notes are specific to each appointment, not shared |
| 4. Counselor opens an appointment without notes | Verify that the notes section is empty or prompts to add notes for the first time |
| 5. Counselor confirms they can only see their own notes | Verify that only notes written by this counselor appear — notes from other counselors do not appear in this view |

**Post-conditions:**
- Each appointment shows only its own session notes
- Notes from different appointments and students are properly isolated
- The counselor can only access notes they personally wrote
