# NOTI-0008: Counselor receives a booking request notification

**Summary:** Verify that when a student books an appointment, the assigned counselor receives a notification about the new booking request.

**Preconditions:**
- User is logged in with a **counselor** account
- A student has just booked an appointment with this counselor

**Scenario 1: Counselor receives new booking notification**

| Step | Expected Behavior |
|------|-------------------|
| 1. The counselor is on any page with the navbar visible | Verify that the notification bell shows a red badge with the unread count (incremented by 1) |
| 2. Counselor clicks the bell icon | Verify that a notification appears with the message "New booking request for {date} at {time}" |
| 3. Verify the notification type icon | Verify that the notification shows a Bell icon (booking_request type) |
| 4. Counselor clicks the notification | Verify that the page navigates to the appointment detail page for the new booking |

**Post-conditions:**
- The counselor is aware of the new booking request and can navigate to act on it
