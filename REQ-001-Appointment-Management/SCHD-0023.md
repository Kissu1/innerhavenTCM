# SCHD-0023: Availability slots grid — empty states

**Summary:** Verify that the time slots grid displays the correct empty state message based on the counselor's schedule configuration.

**Preconditions:**
- User is logged in with a **student** account
- The student is on the booking form with a counselor selected

**Scenario 1: Empty state messages for various availability conditions**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student selects a counselor who has not set up their weekly schedule | Verify that the slots grid shows the message **"This counselor has not configured a weekly schedule yet."** |
| 2. Verify that no time slots are displayed for the unconfigured counselor | Verify that the grid area is empty with only the message shown |
| 3. Student selects a counselor and a date where all slots are taken | Verify that the slots grid shows the message **"All available slots are already booked for this date."** |
| 4. Student selects a counselor and selects today's date when only past slots remain | Verify that the slots grid shows the message **"No future slots remain for today. Try a later date."** |
| 5. Verify that past time slots appear dimmed/disabled and cannot be selected | Verify that clicking on a past slot does nothing |
| 6. Student selects a counselor and a date where the counselor does not work (e.g., Sunday when counselor only works Mon–Fri) | Verify that the slots grid shows the message **"No slots available for this date."** |
