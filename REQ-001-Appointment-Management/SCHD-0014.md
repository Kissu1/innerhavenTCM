# SCHD-0014: Student cancels a pending appointment

**Summary:** Verify that a student can cancel their own pending appointment and the timeslot is freed.

**Preconditions:**
- User is logged in with a **student** account
- The student has a **pending** appointment

**Scenario 1: Cancel a pending appointment**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the appointments page and finds a pending appointment | Verify that the appointment card shows a "Cancel" action in the dropdown menu |
| 2. Student clicks "Cancel" | Verify that a confirmation dialog or prompt appears asking to confirm the cancellation |
| 3. Student confirms the cancellation | Verify that a loading state appears |
| 4. The request completes | Verify that the appointment card's status badge changes to **"Cancelled"** with a red/error color |
| 5. Student opens the appointment detail | Verify that the status is shown as "Cancelled" |
| 6. Student returns to the booking page and checks the same counselor and date | Verify that the previously booked time slot is now available again |

**Post-conditions:**
- The appointment status is changed to "Cancelled"
- The time slot is freed and becomes available for booking
- The appointment card remains visible in the list with a "Cancelled" badge
