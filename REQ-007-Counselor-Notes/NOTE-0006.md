# NOTE-0006: Student receives notification when counselor creates a note

**Summary:** Verify that when a counselor writes session notes for the first time on an appointment, the student receives a notification about it.

**Preconditions:**
- User is logged in with a **student** account who has an appointment
- The appointment does not yet have session notes
- The counselor is about to create session notes for this appointment

**Scenario 1: Notification on first note creation**

| Step | Expected Behavior |
|------|-------------------|
| 1. The counselor creates session notes for the student's appointment (as in NOTE-0001) | Verify that the notes are saved successfully |
| 2. The student checks their notification bell or notifications page | Verify that a new notification appears indicating that session notes are available (e.g., "Your counselor has added session notes for your appointment on [date]") |
| 3. Student clicks on the notification | Verify that the student is taken to the appointment detail page where the new notes are visible |
| 4. The counselor edits the existing notes (as in NOTE-0002) | Verify that no additional notification is sent — the notification is only sent on the first creation, not on subsequent edits |
| 5. Student checks the notification count | Verify that it correctly reflects the new notification and any previously unread ones |

**Post-conditions:**
- The student is notified exactly once when notes are first created
- Editing existing notes does not generate duplicate notifications
- Clicking the notification takes the student directly to the relevant appointment
