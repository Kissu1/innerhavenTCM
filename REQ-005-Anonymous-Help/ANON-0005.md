# ANON-0005: Student cannot start a duplicate conversation with the same counselor

**Summary:** Verify that a student cannot create a second active anonymous conversation with a counselor they already have an active conversation with.

**Preconditions:**
- User is logged in with a **student** account
- The student already has an **active** anonymous conversation with Counselor A

**Scenario 1: Attempt to start a duplicate conversation**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the messaging page and clicks "New Conversation" | Verify that the list of available counselors is displayed |
| 2. Student selects Counselor A (with whom they already have an active conversation) | Verify that instead of opening a new message form, the existing active conversation opens — the student is taken directly to the ongoing chat |
| 3. Alternatively, if the UI allows attempting to create a duplicate, the student submits a new initial message to Counselor A | Verify that a friendly message appears: "You already have an active conversation with this counselor" — a new duplicate conversation is not created |
| 4. Student checks their conversations list | Verify that only one active conversation with Counselor A exists — no duplicate was created |

**Post-conditions:**
- Only one active conversation exists per student-counselor pair
- The student is either redirected to the existing conversation or shown a clear message explaining the situation
- The original conversation and its message history remain intact
