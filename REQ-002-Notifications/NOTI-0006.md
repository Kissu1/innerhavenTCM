# NOTI-0006: Student clicks a session notes notification

**Summary:** Verify that clicking a session notes notification navigates the student to the messaging page.

**Preconditions:**
- User is logged in with a **student** account
- The student has a session_notes notification (e.g., "Your counselor shared session notes for a recent appointment")

**Scenario 1: Click a session notes notification**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student views a session_notes notification | Verify that the notification message reads something like "Your counselor shared session notes for a recent appointment." |
| 2. Student clicks the notification card | Verify that the student is taken to the messaging page where the session notes can be viewed |

**Post-conditions:**
- The student is taken to the messaging page to view the session notes
