# SCHD-0002: Student creates a new appointment (in-person)

**Summary:** Verify that an authenticated student can successfully book an in-person appointment and that the session format "In-person" is correctly recorded.

**Preconditions:**
- User is logged in with a **student** account
- The student navigates to the booking page

**Scenario 1: Successful in-person appointment creation**

| Step | Expected Behavior |
|------|-------------------|
| 1. The booking page loads | Verify that a list of counselors is displayed |
| 2. Student selects a counselor | Verify that the counselor profile card is shown |
| 3. Student selects a future date | Verify that the available time slots are displayed |
| 4. Student clicks on an available time slot | Verify that the slot is highlighted as selected |
| 5. Student selects "In-person" as the session format | Verify that the "In-person" option is highlighted and "Main Campus Lounge" subtitle is shown |
| 6. Student types a reason in the concern textarea | Verify that the text is accepted |
| 7. Student clicks "Confirm Session" | Verify that the request is submitted and a success confirmation or redirect occurs |
| 8. Student navigates to the appointments page | Verify that a new appointment card appears with mode shown as **"In-person"** and status **"Pending"** |
| 9. Student opens the appointment detail | Verify that the detail page shows mode "In-person" and no Google Meet link is displayed |

**Post-conditions:**
- The new appointment card is visible with status "Pending" and mode "In-person"
- No Google Meet link is associated with the appointment
