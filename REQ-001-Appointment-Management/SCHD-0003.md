# SCHD-0003: Student attempts to book with missing required fields

**Summary:** Verify that the system prevents appointment creation when required fields are missing and shows appropriate feedback.

**Preconditions:**
- User is logged in with a **student** account
- The student navigates to the booking page

**Scenario 1: Submit without counselor, date/time, or reason**

| Step | Expected Behavior |
|------|-------------------|
| 1. The booking page loads | Verify that the counselor list and the "Confirm Session" button are displayed |
| 2. Student skips counselor selection, selects a date and time, types a reason, then clicks "Confirm Session" | Verify that the submission is prevented and an error message "Please complete all selections." is displayed |
| 3. Student selects a counselor but does NOT select a date or time slot, then clicks "Confirm Session" | Verify that the submission is prevented and an error message "Please complete all selections." is displayed |
| 4. Student selects a counselor, a future date, and an available time slot, but leaves the concern textarea empty, then clicks "Confirm Session" | Verify that the submission is prevented and an error message "Please complete all selections." is displayed |
