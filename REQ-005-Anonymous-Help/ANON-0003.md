# ANON-0003: Student closes their anonymous conversation

**Summary:** Verify that a student can close an active anonymous conversation when they feel the issue is resolved, and the conversation is marked as closed for both parties.

**Preconditions:**
- User is logged in with a **student** account who has an active anonymous conversation with a counselor
- A few messages have been exchanged in the conversation

**Scenario 1: Student closes the conversation**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student opens the active conversation and feels the issue has been resolved | Verify that the conversation shows the full message history |
| 2. Student clicks "Close Conversation" or a similar option | Verify that a confirmation prompt appears: "Are you sure you want to close this conversation?" |
| 3. Student confirms the closure | Verify that the conversation is marked as closed — a system message appears in the chat: "The user can no longer be reached." |
| 4. Student returns to their conversations list | Verify that the closed conversation is no longer shown in the active list (it may appear in a closed/archived section) |
| 5. The counselor views the same conversation | Verify that the counselor also sees the conversation as closed with the system message, and can no longer send new messages in it |

**Post-conditions:**
- The conversation is closed for both the student and the counselor
- Neither party can send new messages in the closed conversation
- The message history remains readable by both parties
- A system message indicates the conversation was closed
