# SCHD-0010: Student edits a pending appointment (change reason)

**Summary:** Verify that a student can edit the reason of a pending appointment.

**Preconditions:**
- User is logged in with a **student** account
- The student has a **pending** appointment

**Scenario 1: Edit reason of a pending appointment**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the appointments page and finds a pending appointment | Verify that the pending appointment card shows an "Edit" action in the dropdown menu |
| 2. Student clicks "Edit" | Verify that the booking form loads pre-filled with the existing appointment data (counselor, date, time, mode, reason) |
| 3. Verify the confirm button label | Verify that the button reads **"Save Changes"** instead of "Confirm Session" |
| 4. Student clears the existing reason and types a new reason (e.g., "Updated concern — feeling overwhelmed") | Verify that the new text is accepted |
| 5. Student clicks "Save Changes" | Verify that a loading state appears on the button |
| 6. The request completes | Verify that a success confirmation is shown or the page redirects back to the appointment detail |
| 7. Student opens the appointment detail | Verify that the reason displayed matches the updated text entered in Step 4 |

**Post-conditions:**
- The appointment reason is updated
- The appointment remains in "Pending" status
- The appointment card on the appointments list reflects the updated reason preview
