# NOTE-0001: Counselor creates a session note for an appointment

**Summary:** Verify that a counselor can write session notes, recommendations, and a follow-up plan for a completed appointment, and the notes are saved successfully.

**Preconditions:**
- User is logged in with a **counselor** account
- The counselor has an appointment with a student (the appointment does not yet have session notes)

**Scenario 1: Create a new session note**

| Step | Expected Behavior |
|------|-------------------|
| 1. Counselor opens the appointment detail page for a past or completed appointment | Verify that a "Session Notes" section is visible with empty fields or a prompt to add notes |
| 2. Counselor clicks to add or edit session notes | Verify that editable fields appear for: general notes, recommendations, and follow-up plan |
| 3. Counselor writes a summary in the notes field: "Discussed coping strategies for workplace stress. Student responded well to breathing exercises." | Verify that the text is accepted |
| 4. Counselor adds recommendations, each on a new line: "Practice 5-minute breathing exercise daily", "Keep a stress journal for one week" | Verify that each recommendation appears as a separate item |
| 5. Counselor writes a follow-up plan: "Review stress journal in next session. Introduce progressive muscle relaxation." | Verify that the follow-up text is accepted |
| 6. Counselor saves the session notes | Verify that a success message appears and the notes are now displayed in a read-only view showing the notes, numbered recommendations, and follow-up plan |
| 7. Counselor navigates away and returns to the same appointment | Verify that the saved notes are still visible — they persist across page navigation |

**Post-conditions:**
- The session notes are saved and associated with the appointment
- The notes, recommendations, and follow-up plan are all stored
- The counselor can view the notes at any time from the appointment
- The student can now see the notes (see NOTE-0003)
