# AUTH-0001: New user signs up with email and password

**Summary:** Verify that a new user can create an account using their email and password, receive a confirmation email, and verify their email to complete registration.

**Preconditions:**
- The user has not previously registered with this email
- The user is on the sign-up page

**Scenario 1: Complete email/password sign-up flow**

| Step | Expected Behavior |
|------|-------------------|
| 1. User navigates to the sign-up page | Verify that a sign-up form is displayed with fields for email, password, and confirm password |
| 2. User enters a valid email, a strong password, and confirms the password | Verify that the form accepts the input and the password fields match |
| 3. User clicks "Sign Up" | Verify that a loading state appears on the button and a confirmation message is shown: "Check your email for a confirmation link" |
| 4. User checks their email inbox | Verify that a confirmation email is received with a link to verify the account |
| 5. User clicks the confirmation link in the email | Verify that the browser opens and confirms the email — the user is redirected to the dashboard |
| 6. User arrives at the dashboard | Verify that the user is now logged in and can see their dashboard |

**Post-conditions:**
- A new account is created with the provided email
- The user's email is verified
- The user is logged in and can access protected pages
- The user is assigned the default role (student)
