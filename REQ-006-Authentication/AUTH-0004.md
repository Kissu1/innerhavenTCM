# AUTH-0004: User logs out and is redirected to login

**Summary:** Verify that a logged-in user can sign out and is redirected to the login page, with subsequent protected page access blocked.

**Preconditions:**
- User is logged in with a valid session
- The user is on any authenticated page (e.g., dashboard)

**Scenario 1: Logout and access restriction**

| Step | Expected Behavior |
|------|-------------------|
| 1. User clicks the logout button in the navigation bar or user menu | Verify that a brief loading state appears |
| 2. The logout completes | Verify that the user is redirected to the login page |
| 3. User checks the navigation bar (if visible) | Verify that the user's email or name is no longer displayed — the login/sign-up options are shown instead |
| 4. User attempts to navigate directly to a protected page (e.g., `/dashboard` or `/appointments`) | Verify that the user is redirected to the login page — protected pages are not accessible |
| 5. User attempts to use the browser's back button to return to a previously visited protected page | Verify that the page does not load with the user's data — the user is redirected to login again |

**Post-conditions:**
- The user's session is fully terminated
- Protected pages redirect to login until the user logs in again
- No cached authenticated data is visible
