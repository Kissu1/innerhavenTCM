# CNSL-0005: No time slots available — counselor's off-day

**Summary:** Verify that when a student selects a date the counselor does not work (weekend or off-day), the slot grid shows a clear "no availability" message instead of an error.

**Preconditions:**
- User is logged in with a **student** account
- A counselor exists with a Mon/Wed/Fri schedule only

**Scenario 1: Select an off-day and see the empty state**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student selects the counselor on the booking page | Verify that the counselor is selected and the calendar is displayed |
| 2. Student clicks on a Saturday in the calendar | Verify that the time slot grid shows a friendly message: "No available slots for this date" — with no error or blank screen |
| 3. Student clicks on a Tuesday (also an off-day for this counselor) | Verify that the same "no availability" message appears |
| 4. Student clicks on a Wednesday (a scheduled workday) | Verify that time slots load normally, confirming the schedule is correct and off-days are handled properly |

**Post-conditions:**
- Off-days show a clear, friendly "no availability" message
- Switching to a scheduled day immediately shows available slots
- No error messages or broken UI states appear
