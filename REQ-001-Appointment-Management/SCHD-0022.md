# SCHD-0022: Empty appointments list

**Summary:** Verify that the appointments page handles a user with no appointments gracefully.

**Preconditions:**
- User is logged in with a **student** account
- The student has **no appointments** in the system

**Scenario 1: Empty list display**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the appointments page | Verify that the page loads without errors |
| 2. Verify the displayed state | Verify that an empty state message is displayed (e.g., "No appointments yet" or similar) |
