# SCHD-0006: Unauthenticated user attempts to access the booking page

**Summary:** Verify that unauthenticated users are redirected away from the booking page.

**Preconditions:**
- User is **not logged in**

**Scenario 1: Access booking page without authentication**

| Step | Expected Behavior |
|------|-------------------|
| 1. Navigate to the booking/new appointment page while logged out | Verify that the user is redirected to the login page or a login prompt is displayed |
