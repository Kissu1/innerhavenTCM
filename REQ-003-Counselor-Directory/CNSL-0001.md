# CNSL-0001: Student browses the counselor directory (happy path)

**Summary:** Verify that an authenticated student can browse the full counselor directory and view counselor profile cards with key information.

**Preconditions:**
- User is logged in with a **student** account
- At least three counselors exist in the system, each with a profile (name, specialization, bio/description)

**Scenario 1: Directory loads with all counselors**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the counselors page | Verify that the page loads without errors and a loading skeleton or spinner is briefly shown |
| 2. The counselor list renders | Verify that all available counselors are displayed as individual cards or list items |
| 3. Inspect a counselor card | Verify that each card shows the counselor's avatar (or initials fallback), full name, and specialization/title |
| 4. Student scrolls through the directory | Verify that all counselors are rendered (no missing entries), and the layout is responsive |
| 5. Student clicks on a counselor card | Verify that the selected counselor's profile panel appears showing: name, specialization, about/bio text, and an option to switch to a different counselor |
| 6. Student clicks "Switch Counselor" and selects a different counselor | Verify that the profile panel updates to show the newly selected counselor's information without stale data from the previous selection |

**Post-conditions:**
- The directory remains accessible and all counselor profiles display correctly
- Switching between counselors updates the UI without stale data from the previous selection
