# NOTI-0004: Student views the full notifications page

**Summary:** Verify that the student can navigate to a dedicated notifications page that displays all notifications in a scrollable list.

**Preconditions:**
- User is logged in with a **student** account
- The student has multiple notifications (more than 5)

**Scenario 1: Navigate to and view the full notifications page**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the notifications page | Verify that the page loads with a list of all notifications |
| 2. Verify the notification cards | Verify that each notification is displayed as a card with an icon that matches the notification type, the notification message, and when it was received |
| 3. Verify the icons match notification types | Verify that booking requests, approvals, declines, and reschedules each have a distinct, recognizable icon |
| 4. Scroll through the list | Verify that the list is scrollable and all notifications are accessible |
| 5. Verify that all notifications are automatically marked as read | Verify that after the page loads, all notifications appear in the read state (dimmed, no longer bold) |

**Post-conditions:**
- All notifications are visible on the page
- All notifications are automatically marked as read when the page loads
