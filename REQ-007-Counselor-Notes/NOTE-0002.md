# NOTE-0002: Counselor edits an existing session note

**Summary:** Verify that a counselor can return to an appointment and update previously written session notes, recommendations, or follow-up plans.

**Preconditions:**
- User is logged in with a **counselor** account
- The counselor has an appointment with existing session notes (created via NOTE-0001)

**Scenario 1: Edit existing session notes**

| Step | Expected Behavior |
|------|-------------------|
| 1. Counselor opens the appointment detail page that already has session notes | Verify that the existing notes, recommendations, and follow-up plan are displayed in read-only view |
| 2. Counselor clicks "Edit" or enters edit mode | Verify that the fields become editable and are pre-filled with the existing content |
| 3. Counselor updates the notes field: adds "Student reports improvement in sleep quality since last session." | Verify that the new text is appended or replaced as typed |
| 4. Counselor adds a new recommendation: "Continue with evening wind-down routine" | Verify that the new recommendation is added without removing existing ones |
| 5. Counselor saves the changes | Verify that a success message appears and the updated notes are displayed with all changes preserved |
| 6. Counselor navigates away and returns | Verify that the updated notes persist — the old version is replaced |

**Post-conditions:**
- The session notes reflect all updates
- Previous content that was not changed remains intact
- New recommendations are added alongside existing ones
- The student sees the updated notes (not the old version)
