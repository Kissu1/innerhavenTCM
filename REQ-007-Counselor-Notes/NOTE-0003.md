# NOTE-0003: Student views session notes from their counselor

**Summary:** Verify that a student can view the session notes, recommendations, and follow-up plan that their counselor wrote after an appointment.

**Preconditions:**
- User is logged in with a **student** account
- The student has an appointment for which the counselor has written session notes

**Scenario 1: Student reads counselor's session notes**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to their appointments page and opens the appointment with session notes | Verify that a "Session Notes" section is visible on the appointment detail page |
| 2. Student views the notes section | Verify that the counselor's general notes are displayed in a readable format |
| 3. Student views the recommendations | Verify that the recommendations appear as a numbered or bulleted list |
| 4. Student views the follow-up plan | Verify that the follow-up plan text is displayed |
| 5. Student checks for any edit controls | Verify that there are no edit buttons, text fields, or save options — the notes are read-only for students |
| 6. Student navigates to a different appointment that does not have session notes | Verify that the notes section is either empty or shows a message indicating no notes have been added yet |

**Post-conditions:**
- The student can read all session notes written by the counselor
- The notes are displayed in a clear, organized format
- No editing functionality is available to the student
