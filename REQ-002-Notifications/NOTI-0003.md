# NOTI-0003: Student marks all notifications as read via bell dropdown

**Summary:** Verify that opening the notification bell dropdown automatically marks all unread notifications as read.

**Preconditions:**
- User is logged in with a **student** account
- At least one unread notification exists for the student
- The notification bell shows a red badge with an unread count

**Scenario 1: Auto mark-all-on-open**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student clicks the bell icon to open the dropdown | Verify that the dropdown opens and the notifications are displayed |
| 2. Wait a moment for the mark-all action to complete | Verify that all notifications in the dropdown change from unread styling (bold, primary border) to read styling (dimmed, gray border) |
| 3. Close the dropdown and check the bell icon | Verify that the red unread badge is no longer displayed on the bell icon |
| 4. Open the dropdown again | Verify that all notifications still appear with read styling (no unread items) |

**Post-conditions:**
- All notifications for the student are marked as read
- The unread badge on the bell icon is hidden
- The notifications page also reflects all notifications as read
