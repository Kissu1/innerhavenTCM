# ANON-0001: Student starts an anonymous conversation with a counselor

**Summary:** Verify that a student can browse available counselors, select one, write an initial message, and start an anonymous conversation without revealing their identity.

**Preconditions:**
- User is logged in with a **student** account
- At least two counselors exist in the system
- The student has no active conversation with the selected counselor

**Scenario 1: Start a new anonymous conversation**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the messaging page and clicks "New Conversation" | Verify that a list of available counselors is displayed with their names, specializations, and avatars |
| 2. Student selects a counselor from the list | Verify that the counselor is highlighted and a message form appears |
| 3. Student types an initial message describing what they need help with (e.g., "I've been feeling really anxious about my exams lately") | Verify that the message is accepted and a character count is shown |
| 4. Student submits the message | Verify that a brief loading indicator appears, then the conversation opens showing the sent message |
| 5. Student checks the conversation header | Verify that they can see the counselor's name and avatar — the conversation is not anonymous from the student's perspective |
| 6. The selected counselor logs in and navigates to their anonymous requests page | Verify that a new conversation appears in their queue with a pseudonymous label (e.g., "ANON-A1B2") — the counselor cannot see the student's real name |
| 7. Counselor opens the conversation | Verify that the student's initial message is visible to the counselor |

**Post-conditions:**
- An active conversation exists between the student and the counselor
- The student sees the counselor's real identity
- The counselor sees only a pseudonymous label for the student
- The initial message is delivered and readable by both parties
