# AUTH-0002: User logs in with email and password

**Summary:** Verify that a registered user can log in with their email and password and be directed to their role-appropriate dashboard.

**Preconditions:**
- A user account exists with a verified email and password
- The user is on the login page

**Scenario 1: Successful login**

| Step | Expected Behavior |
|------|-------------------|
| 1. User navigates to the login page | Verify that a login form is displayed with fields for email and password |
| 2. User enters their registered email and correct password | Verify that the form accepts the input |
| 3. User clicks "Log In" | Verify that a loading state appears on the button briefly |
| 4. The login completes | Verify that the user is redirected to their dashboard — not the login page |
| 5. User checks the navigation bar | Verify that the user's email or name is displayed, indicating they are logged in (and a logout option is available) |
| 6. User navigates to a protected page (e.g., appointments or settings) | Verify that the page loads successfully — the user is not redirected back to login |

**Post-conditions:**
- The user is authenticated and can access all pages appropriate for their role
- The session persists across page navigation
- The user's identity is reflected in the navigation bar
