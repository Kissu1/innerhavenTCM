# NOTI-0010: Notifications page shows empty state

**Summary:** Verify that the notifications page displays a proper empty state when the user has no notifications.

**Preconditions:**
- User is logged in with a **student** account
- The student has **no notifications**

**Scenario 1: Empty notifications page**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the notifications page | Verify that the page loads without errors |
| 2. Verify the displayed state | Verify that the message **"No notifications yet"** is displayed centered on the page |
| 3. Check the notification bell in the navbar | Verify that no red badge appears on the bell icon |

**Post-conditions:**
- The empty state is displayed gracefully with no errors
