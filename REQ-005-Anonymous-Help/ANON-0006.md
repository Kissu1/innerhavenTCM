# ANON-0006: Counselor views their queue of active anonymous conversations

**Summary:** Verify that a counselor can view all active anonymous conversations assigned to them, see the anonymous labels, and select a conversation to respond to.

**Preconditions:**
- User is logged in with a **counselor** account
- At least three different students have started anonymous conversations with this counselor, each with recent messages

**Scenario 1: View and navigate the anonymous request queue**

| Step | Expected Behavior |
|------|-------------------|
| 1. Counselor navigates to their anonymous requests page | Verify that a list of active conversations is displayed |
| 2. Counselor scans the conversation list | Verify that each conversation shows: a pseudonymous label (e.g., "ANON-A1B2", "ANON-C3D4"), a preview of the last message, and how long ago the last message was sent |
| 3. Counselor checks that student identities are hidden | Verify that no real student names, emails, or profile information appear anywhere in the queue — only anonymous labels are shown |
| 4. Counselor clicks on the most recent conversation | Verify that the full message history for that conversation opens |
| 5. Counselor looks at the other conversations still in the queue | Verify that they remain accessible — the counselor can switch between conversations |
| 6. Counselor checks for any closed conversations | Verify that closed conversations are separated from the active queue (e.g., in a "Closed" or "Archived" tab) |

**Post-conditions:**
- The counselor can see all their active anonymous conversations
- Student identities remain fully hidden — only anonymous labels are visible
- The counselor can open and respond to any active conversation
- Closed conversations are separated from active ones
