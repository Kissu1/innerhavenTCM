# ANON-0004: Counselor closes an anonymous conversation

**Summary:** Verify that a counselor can close an active anonymous conversation from their end, and the closure is reflected for the student as well.

**Preconditions:**
- User is logged in with a **counselor** account who has an active anonymous conversation in their queue
- Messages have been exchanged with the anonymous student

**Scenario 1: Counselor closes the conversation**

| Step | Expected Behavior |
|------|-------------------|
| 1. Counselor opens the active conversation from their queue | Verify that the conversation shows the message history with the student's anonymous label |
| 2. Counselor clicks "Remove this thread" or a similar close option | Verify that a confirmation prompt appears: "The conversation with [ANON-XXXX] will be closed. The student will no longer be able to send messages in this thread, but you will still be able to view the history." |
| 3. Counselor confirms the removal | Verify that the conversation is closed — a system message appears: "This conversation has been closed by the counselor." |
| 4. Counselor returns to their queue | Verify that the closed conversation moves out of the active queue into a closed or archived section |
| 5. The student opens the same conversation | Verify that the student also sees the conversation as closed with the system message, and can no longer send new messages |

**Post-conditions:**
- The conversation is closed for both the counselor and the student
- Neither party can send new messages, but both can still view the history
- A system message indicates the conversation was closed by the counselor
