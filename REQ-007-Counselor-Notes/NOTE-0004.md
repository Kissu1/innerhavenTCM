# NOTE-0004: Student cannot create or edit session notes

**Summary:** Verify that a student has no ability to create, edit, or modify session notes — notes are exclusively managed by counselors.

**Preconditions:**
- User is logged in with a **student** account
- The student has an appointment (with or without existing session notes)

**Scenario 1: Student attempts to interact with session notes**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student opens an appointment that has session notes | Verify that the notes are displayed in read-only format — no "Edit" or "Save" buttons appear |
| 2. Student opens an appointment that does not have session notes | Verify that no "Add Notes" or "Create Notes" button is available — the notes section either shows a placeholder or is absent |
| 3. Student attempts to access any notes-related actions in the UI | Verify that there are no controls or menu items that would allow the student to create or modify notes |

**Post-conditions:**
- Students can only view session notes
- No path exists in the UI for a student to create or edit notes
- The counselor retains exclusive control over note creation and editing
