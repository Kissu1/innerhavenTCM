# NOTI-0011: Notification badge shows 99+ for large unread counts

**Summary:** Verify that when a user has more than 99 unread notifications, the badge displays "99+" instead of the actual count.

**Preconditions:**
- User is logged in with a **student** account
- The student has more than 99 unread notifications

**Scenario 1: Large unread count display**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student is on any page with the navbar visible | Verify that the red badge on the bell icon displays **"99+"** instead of the actual count |

**Post-conditions:**
- The badge correctly caps at "99+" for large counts
