# CNSL-0004: Empty counselor directory

**Summary:** Verify that the counselors page handles the case where no counselors exist in the system gracefully, showing an appropriate empty state instead of an error.

**Preconditions:**
- User is logged in with a **student** account
- **No counselors** exist in the system (no profiles have been added yet)

**Scenario 1: Empty directory display**

| Step | Expected Behavior |
|------|-------------------|
| 1. Student navigates to the counselors page | Verify that the page loads without errors |
| 2. The page renders | Verify that an empty state message is displayed (e.g., "No counselors available at this time" or similar) |
| 3. Inspect the page | Verify that no counselor cards are rendered and the layout does not break or show a raw error |
| 4. Student navigates to the booking page | Verify that the counselor selection area also shows an empty state or a message indicating no counselors are available for booking |

**Post-conditions:**
- The UI handles the empty state gracefully without console errors or layout shifts
- The student can still navigate to other pages normally
