# SCHD-0018: Counselor approves a pending in-person appointment

**Summary:** Verify that approving an in-person appointment does NOT generate a Google Meet link and the approval succeeds without Google interaction.

**Preconditions:**
- User is logged in with a **counselor** account
- A student has a **pending** **in-person** appointment with this counselor

**Scenario 1: Approve an in-person appointment**

| Step | Expected Behavior |
|------|-------------------|
| 1. Counselor navigates to the appointments page and finds a pending in-person appointment | Verify that the appointment card shows an "Accept" action |
| 2. Counselor clicks "Accept" | Verify that a loading state appears |
| 3. The request completes | Verify that the appointment card's status badge changes to **"Approved"** |
| 4. Counselor opens the appointment detail | Verify that the mode is shown as "In-person" |
| 5. Verify that no Google Meet link is displayed | Verify that no "Join Session Now" button or meeting link appears |

**Post-conditions:**
- The appointment status is "Approved"
- No Google Meet link is generated or stored
