# AUTH-0003: User resets forgotten password

**Summary:** Verify that a user who has forgotten their password can request a reset link, set a new password, and log in with it.

**Preconditions:**
- A user account exists with a verified email
- The user does not remember their password

**Scenario 1: Complete password reset flow**

| Step | Expected Behavior |
|------|-------------------|
| 1. User navigates to the login page and clicks "Forgot your password?" | Verify that the password reset form is displayed with an email field |
| 2. User enters their registered email and submits the form | Verify that a confirmation message appears: "Check your email for a password reset link" |
| 3. User checks their email inbox | Verify that a password reset email is received with a link |
| 4. User clicks the reset link in the email | Verify that the browser opens to a page where the user can enter a new password |
| 5. User enters a new password and confirms it | Verify that the form accepts the input |
| 6. User submits the new password | Verify that a success message appears: "Password updated successfully" — the user is redirected to the dashboard |
| 7. User logs out and attempts to log in with the new password | Verify that the login succeeds with the new password |

**Post-conditions:**
- The user's password is updated to the new one
- The old password no longer works
- The user can log in and access their account normally
