# SCHD-0001: Student creates a new appointment (online)

**Summary:** Verify that an authenticated student can successfully book an online appointment by selecting a counselor, a future date, an available time slot, entering a reason, and confirming the session.

**Preconditions:**
- User is logged in with a **student** account
- The student navigates to the booking page (e.g., clicks "Book Appointment" or navigates to the new appointment page)

**Scenario 1: Successful online appointment creation**

| Step | Expected Behavior |
|------|-------------------|
| 1. The booking page loads | Verify that a list of counselors is displayed, each showing the counselor's avatar (or initials), name, and specialization |
| 2. Student clicks on a counselor card | Verify that the counselor is highlighted as selected |
| 3. The counselor profile card appears | Verify that it shows the counselor's name, specialization, about/bio text, and a "Switch Counselor" option |
| 4. Student clicks on a future date in the calendar | Verify that the available time slots for that date are loaded and displayed in a grid |
| 5. Student clicks on an available time slot | Verify that the selected slot is visually highlighted (e.g., filled/outlined differently from unselected slots) |
| 6. The session summary sidebar updates | Verify that the sidebar shows the selected date, selected time, and the counselor's name |
| 7. Student selects "Google Meet" as the session format | Verify that the "Google Meet" option is highlighted and "Secure video call link" subtitle is shown |
| 8. Student types a reason in the concern textarea (e.g., "I need help with anxiety") | Verify that the text is accepted and the character count does not exceed 250 |
| 9. Student clicks the "Confirm Session" button | Verify that a loading state appears on the button (e.g., spinner or "Saving..." text) |
| 10. The request completes | Verify that a success confirmation is displayed or the page redirects to the appointments page |
| 11. Student navigates to the appointments page or dashboard | Verify that a new appointment card appears with the selected counselor's name, the selected date, the selected time, the mode shown as "online", and the status displayed as **"Pending"** |
| 12. Student clicks on the newly created appointment card | Verify that the appointment detail page opens showing the counselor name, date, time range (start – end), mode "online", the reason entered, and status "Pending" |
| 13. Student returns to the booking page and selects the same counselor and same date | Verify that the previously booked time slot no longer appears as available |

**Post-conditions:**
- The new appointment card is visible on the dashboard and appointments list with status "Pending"
- The booked time slot is no longer available for that counselor on that date
- A notification is generated for the counselor about the new booking request
